# SnowDay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Vercel-ready Next.js app that forecasts hyperlocal US snowfall with real-uncertainty ranges, predicts school closures transparently, and reports official closure status separately from predictions.

**Architecture:** Pure computation modules (`lib/snow`, `lib/predict`, `lib/official/status`) are unit-tested and I/O-free; thin I/O adapters (`lib/weather`, `lib/geo`, `lib/schools`, `lib/official/verify`) feed them; Next.js route handlers validate, rate-limit and cache; React server/client components render.

**Tech Stack:** Next.js 15 App Router, TypeScript strict, Tailwind CSS 4, Framer Motion, Lucide, Recharts, MapLibre GL, zod, @supabase/supabase-js, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-09-snowday-design.md`

## Global Constraints

- Never display a number not derived from a real API response; missing data renders an explicit unavailable state.
- Never set `officially_closed`/`officially_delayed` from a prediction.
- Snow thresholds scale by preparedness multiplier `m` (spec §5); ice/cold by `sqrt(m)`.
- Low/likely/high = ensemble p10/p50/p90; fallback label `"model-spread"`.
- Server secrets (`SUPABASE_SERVICE_ROLE_KEY`) never imported into client components.
- `prefers-reduced-motion` disables snowfall canvas and entrance motion.
- Units: compute metric, display inches + cm.
- All local-time windows use the location's IANA timezone from Open-Meteo.

## Review Focus

- Location with zero snow in 72 h (Miami, Honolulu) → all totals 0, "No snow expected", closure engine near 0%, no NaN. → Task 3/5 tests.
- Ensemble API failure → model-spread fallback with label, not crash. → Task 3 test.
- Search input that is a 5-digit ZIP vs a city vs a street address vs junk (`"<script>"`, 300 chars) → correct geocoder or 400. → Task 7 test.
- Feed text "Schools will open on time, no delay" must NOT classify as delayed. → Task 6 test.
- Timezone: Alaska / Hawaii school-day windows computed in local time, not UTC. → Task 3 test.
